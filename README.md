# ⚡ RISKVORTEX

An institutional-grade financial risk analytics engine for portfolio simulation and macro stress testing.

🚀 **Live App:** [riskvortex.streamlit.app](https://riskvortex.streamlit.app)

---

## 🔑 Core Features
- **Monte Carlo Simulations:** 5,000+ stochastic paths to calculate 95% Value-at-Risk (VaR) & Expected Shortfall (CVaR).
- **Macro Stress Testing:** Replay historical financial crises (e.g., 2008, 2020) to stress-test portfolio resilience.
- **Factor Attribution:** Dynamic CAPM metrics including Market Beta ($\beta$) and Jensen's Alpha ($\alpha$).
- **Bankruptcy Prediction:** Altman Z-Score modeling for fundamental corporate health analysis.

## 🛠️ Tech Stack
Python | Streamlit | NumPy | Pandas | Plotly | yfinance
